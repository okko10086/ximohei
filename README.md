# 戏墨字体 · Ximo Fonts

两个中文字体家族，共 14 个字重：

- **戏墨黑 SC** —— 基于**思源黑体**改造的现代黑体，六字重，取「大字面、紧中宫、略窄挺」的调性
- **戏墨宋 SC** —— 基于**思源宋体**改造的宋体，四字重，只做中宫收紧与字面调整

各自另有**水墨标题体**，轮廓带水渍边缘，用于大字号标题。

**SIL Open Font License 1.1，免费商用。**

本仓库同时是这两款字体的**落地页**（GitHub Pages）与网页字体分发点。

覆盖 65,535 字形 / 44,812 个 cmap 字符 / 20,976 个基本区汉字，含扩展 A 区、拉丁字母、
数字、注音、假名、谚文与全套中文标点。完整保留 `GPOS`/`GSUB` 与 `vhea`/`vmtx` **竖排**支持。

### 设计说明

思源黑体的轮廓**已经合并**（一个「十」字只有一条闭合轮廓），无法按单条笔画加粗减细。
全部改造通过**全局坐标变形**完成，四个旋钮：

1. **中宫收紧 `k = 0.08`** —— 对局部缩放率建模，笔画只渐变变细、绝不增粗
2. **字面纵横比 `sx=1.005, sy=1.062`** —— 字面由源字体的 0.992 收窄到约 0.937
3. **字面率补偿** —— 抵消中宫收紧带来的字面缩小
4. **字重体系** —— 沿用思源黑体六字重骨架，保证 InDesign / Photoshop / CSS 里字重梯度正确

变形严格限定为 `x′=f(x)`、`y′=g(y)`，两者不交叉——这是 Type 2 charstring
编码正确性的硬约束（`hlineto` / `hvcurveto` 带隐式坐标，靠"相等"成立）。

### 设计说明：宋体不加笔画对比

这是与黑体最关键的差别。**宋体一律不接笔画对比变换**，依据是实测：

思源宋体 Regular 的「一」字，横画本体仅从 y=398 到 y=431 —— **厚度 33 单位**，
而两端三角衬线把它撑到 y=514（包围盒高 116）。作为对照，思源黑体 Heavy 的竖画厚约 150 单位。

宋体本就靠横细竖粗立骨，再加对比会把横画削成发丝，结构直接塌掉。

中宫收紧与字面调整对宋体同样适用，但水墨振幅由**横画**而非竖画决定，
整体比黑体小一档。源码里保留了反面记录（实验台的 `宋_加对比_错` 候选），可以清楚看到结构塌掉的样子。

## 三、水墨标题体

水墨位移需要 16–20 单位才在大字号下可见。Regular 的竖画只有约 55 单位，
位移会直接压穿笔画——**水墨字本就该用重墨写成**，所以它只从粗字重派生。

两级变换叠在文本字体之上：

1. **方向性笔画对比**（仅黑体）—— 沿轮廓法线偏移，法线竖直处（横画边缘）内缩、
   法线水平处（竖画边缘）外扩。实测对比度由 1.000 提升到约 1.6。
2. **水渍边缘** —— 二维值噪声沿法线偏移轮廓，波长与笔画宽度同量级（40–60 单位）。

### 字体只能编码形状，不能编码色调

水渍那圈深浅不匀的渍痕，是墨水浓度在纸纤维上干燥后的渐变——属于**栅格信息**。
OpenType 的轮廓里没有灰阶。

所以完整的水墨效果需要两层：字形层提供**不规则的边缘**，纹理层（PNG，正片叠底）
提供**深浅与晕染**。字始终是实心墨——纹理只做浓淡，绝不把字洗灰。

### 几何安全由构造保证

沿法线偏移一旦超过局部半厚，轮廓就会自交或翻转绕向——字就坏了，而且**看起来可能
只是「有点怪」，不一定会立刻暴露**。三级参数式限幅都不够：

| 方案 | 结果 |
|---|---|
| 全局常量上限 | 「谱」字 71×34 的小横画被削穿 |
| 按轮廓 bbox 限幅 | 实验台 170 字全过，**全量 65524 字仍 235/840 处翻转** |
| 逐点局部厚度限幅 | 压力集 1538 字从 8/178 降到 4/12 处翻转 |

残余翻转来自更隐蔽的机制：**锐角与尖刺处的法线估计会指反**，靠调小幅度治不好。
故改为**逐字形检测 + 自适应降级**：发现轮廓翻转或压没就降低强度重试
（1.0 → 0.6 → 0.35 → 0），几何安全由构造保证。

实测降级率：黑体水墨 0.55% / 1.32%，宋体水墨 0.00% / 0.07%。

## 四、网页字体

```css
@font-face {
  font-family: 'Xi Mo Hei SC';
  src: url('fonts/ximohai-regular.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
}
@font-face {
  font-family: 'Xi Mo Song SC';
  src: url('fonts/ximosong-regular.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
}
body { font-family: 'Xi Mo Hei SC', sans-serif; }
```

| 前缀 | 内容 | 体积 |
|---|---|---|
| `ximohai-*` / `ximosong-*` | 落地页自用子集（210 字） | 约 81–91 KB / 字重 |
| `full-ximohai-*` / `full-ximosong-*` | GB2312 完整子集（7,690 字符），覆盖现代中文约 99.7% | 约 2.5–3.2 MB |
| `ximoink-*` / `ximosongink-*` | 水墨标题体自用子集 | 约 90–97 KB / 字重 |

> 桌面 OTF 每个 11.5–18 MB，**未随仓库分发**——见 [Releases](../../releases) 下载，本仓库只放网页用 WOFF2 子集。
